102 Etiquetas HTML

Tabla con el número, nombre, descripción, ejemplo de uso y un dato adicional de cada etiqueta.

Número Nombre de la Etiqueta Descripción Ejemplo de Uso Elemento Adicional
1<a>Define un hipervínculo. Enlaza una página con otra o con un recurso.<a href="https://www.example.com">Visita Ejemplo</a>Atributo target="_blank" para abrir en una pestaña nueva.
2<abbr>Define una abreviatura y muestra su significado al pasar el mouse.<abbr title="HyperText Markup Language">HTML</abbr>El texto del atributo title sale como ayuda.
3<address>Define la información de contacto del autor o del sitio.<address>Calle 1, Santo Domingo</address>El navegador suele mostrarlo en cursiva.
4<area>Define una zona clicable dentro de un mapa de imagen.<area shape="rect" coords="0,0,50,50" href="a.html" alt="Zona">Se usa dentro de la etiqueta map.
5<article>Define un contenido independiente, como una noticia o un post.<article>Contenido del artículo</article>Suele llevar su propio encabezado h2.
6<aside>Define contenido relacionado pero aparte, como una barra lateral.<aside>Datos curiosos</aside>Muy usado para barras laterales.
7<audio>Inserta un reproductor de audio.<audio src="sonido.mp3" controls></audio>El atributo controls muestra los botones de play y pausa.
8<b>Pone el texto en negrita sin darle importancia especial.<b>Texto en negrita</b>Para dar importancia real es mejor usar strong.
9<base>Define la URL base para todos los enlaces relativos de la página.<base href="https://www.example.com/">Va dentro de head y solo se usa una vez.
10<bdi>Aísla un texto que puede tener otra dirección de escritura.<bdi>مرحبا</bdi>Útil con nombres de usuario en distintos idiomas.
11<bdo>Cambia la dirección del texto (izquierda a derecha o al revés).<bdo dir="rtl">Texto al revés</bdo>El atributo dir acepta ltr y rtl.
12<blockquote>Define una cita larga tomada de otra fuente.<blockquote cite="https://example.com">Una cita larga.</blockquote>El atributo cite guarda la fuente.
13<body>Contiene todo el contenido visible de la página.<body>Contenido visible</body>Solo puede haber una por documento.
14<br>Inserta un salto de línea.Línea 1<br>Línea 2Es una etiqueta vacía: no tiene cierre.
15<button>Crea un botón en el que se puede hacer clic.<button type="button">Enviar</button>El atributo type puede ser button, submit o reset.
16<canvas>Crea un área para dibujar gráficos con JavaScript.<canvas id="lienzo" width="200" height="100"></canvas>Sin JavaScript no muestra nada.
17<caption>Define el título de una tabla.<caption>Lista de etiquetas</caption>Va justo después de abrir table.
18<cite>Indica el título de una obra (libro, película, canción).<cite>Don Quijote</cite>Normalmente se muestra en cursiva.
19<code>Muestra un fragmento de código de computadora.<code>console.log("Hola")</code>Usa fuente monoespaciada.
20<col>Define propiedades para una columna de una tabla.<col style="background-color: yellow">Va dentro de colgroup y no tiene cierre.
21<colgroup>Agrupa columnas de una tabla para darles estilo.<colgroup><col><col></colgroup>Va antes de las filas de la tabla.
22<data>Asocia un valor legible por máquinas al contenido.<data value="25">Veinticinco</data>El atributo value guarda el dato real.
23<datalist>Ofrece una lista de opciones sugeridas para un input.<datalist id="frutas"><option value="Mango"></datalist>Se conecta al input con el atributo list.
24<dd>Define la descripción de un término en una lista de definiciones.<dd>Lenguaje de marcado</dd>Va dentro de dl, después de dt.
25<del>Marca texto eliminado (se ve tachado).<del>Texto viejo</del>Se combina con ins para mostrar cambios.
26<details>Crea un bloque que se puede abrir y cerrar.<details><summary>Ver más</summary>Texto oculto</details>El atributo open lo deja abierto al inicio.
27<dfn>Marca el término que se está definiendo.<dfn>HTML</dfn> es un lenguajeNormalmente se muestra en cursiva.
28<dialog>Define una ventana de diálogo o cuadro emergente.<dialog open>Hola</dialog>Se abre y cierra con JavaScript (show y close).
29<div>Define una sección o contenedor genérico del documento.<div>Contenido del div</div>Se usa mucho para aplicar estilos CSS y organizar el diseño.
30<dl>Crea una lista de definiciones.<dl><dt>HTML</dt><dd>Lenguaje web</dd></dl>Combina dt y dd.
31<dt>Define el término en una lista de definiciones.<dt>CSS</dt>Va dentro de dl.
32<em>Da énfasis al texto (se muestra en cursiva).Es <em>muy</em> importanteCambia el sentido de la frase al leerla.
33<embed>Incrusta contenido externo, como un PDF o un plugin.<embed src="documento.pdf" width="300" height="200">No tiene etiqueta de cierre.
34<fieldset>Agrupa varios campos de un formulario.<fieldset><legend>Datos</legend></fieldset>Dibuja un borde alrededor del grupo.
35<figcaption>Define el pie o descripción de una figura.<figcaption>Foto de la playa</figcaption>Va dentro de figure.
36<figure>Agrupa una imagen, gráfico o código con su descripción.<figure><img src="a.jpg" alt="Playa"></figure>Se acompaña de figcaption.
37<footer>Define el pie de página de la página o de una sección.<footer>© 2026 Mi sitio</footer>Suele llevar derechos de autor y contacto.
38<form>Crea un formulario para recoger datos del usuario.<form action="/enviar" method="post"></form>method puede ser get o post.
39<h1>Define el encabezado más importante de la página.<h1>Este es un Encabezado</h1>Los encabezados van de h1 (más importante) a h6 (menos importante).
40<h2>Define un encabezado de segundo nivel.<h2>Subtítulo</h2>Se usa para dividir las secciones principales.
41<h3>Define un encabezado de tercer nivel.<h3>Sub-subtítulo</h3>Va dentro de una sección con h2.
42<h4>Define un encabezado de cuarto nivel.<h4>Título menor</h4>No te saltes niveles al usarlos.
43<h5>Define un encabezado de quinto nivel.<h5>Título pequeño</h5>Se usa poco.
44<h6>Define el encabezado de menor importancia.<h6>Título mínimo</h6>Es el último nivel de encabezado.
45<head>Contiene la información invisible de la página (título, metadatos, estilos).<head><title>Mi página</title></head>Va antes del body.
46<header>Define la cabecera de la página o de una sección.<header><h1>Mi sitio</h1></header>Suele contener logo, título y menú.
47<hgroup>Agrupa un título con su subtítulo.<hgroup><h1>Título</h1><p>Subtítulo</p></hgroup>Sirve para que el subtítulo no cuente como un nuevo encabezado.
48<hr>Dibuja una línea horizontal que separa contenido.<hr>Es una etiqueta vacía: no tiene cierre.
49<html>Es la raíz que envuelve todo el documento HTML.<html lang="es">...</html>El atributo lang indica el idioma de la página.
50<i>Muestra el texto en cursiva (voz distinta, términos técnicos).<i>Texto en cursiva</i>Para énfasis real es mejor usar em.
51<iframe>Incrusta otra página web dentro de la tuya.<iframe src="https://example.com" width="300" height="200"></iframe>Algunos sitios no permiten ser incrustados.
52<img>Incrusta una imagen en la página.<img src="imagen.jpg" alt="Descripción de la imagen">Importante incluir el atributo alt para accesibilidad.
53<input>Crea un campo donde el usuario escribe o elige datos.<input type="text" name="nombre">El atributo type cambia el tipo: text, email, password, checkbox, etc.
54<ins>Marca texto insertado o añadido (se ve subrayado).<ins>Texto nuevo</ins>Es el contrario de del.
55<kbd>Indica una tecla o entrada de teclado.Presiona <kbd>Ctrl</kbd> + <kbd>C</kbd>Usa fuente monoespaciada.
56<label>Define la etiqueta (texto) de un campo de formulario.<label for="correo">Correo:</label>El atributo for debe coincidir con el id del input.
57<legend>Define el título de un fieldset.<legend>Datos personales</legend>Va dentro de fieldset.
58<li>Define un elemento de una lista.<li>Primer elemento</li>Va dentro de ul u ol.
59<link>Conecta el documento con un recurso externo, como un CSS.<link rel="stylesheet" href="estilos.css">Va en head y no tiene cierre.
60<main>Define el contenido principal de la página.<main>Contenido principal</main>Solo debe haber uno por página.
61<map>Define un mapa de imagen con zonas clicables.<map name="mapa"><area ...></map>Se conecta a la imagen con usemap.
62<mark>Resalta texto, como con un marcador amarillo.<mark>Texto resaltado</mark>Muy usado para resultados de búsqueda.
63<menu>Define una lista de comandos o menú de opciones.<menu><li>Abrir</li><li>Guardar</li></menu>Es parecido a ul.
64<meta>Define metadatos de la página (codificación, descripción, viewport).<meta charset="UTF-8">Va en head y no tiene cierre.
65<meter>Muestra un valor dentro de un rango conocido.<meter value="6" min="0" max="10">6 de 10</meter>Se usa para medidas, no para progreso.
66<nav>Define un bloque de enlaces de navegación.<nav><a href="/">Inicio</a></nav>Úsalo para menús principales.
67<noscript>Muestra contenido alternativo si JavaScript está desactivado.<noscript>Activa JavaScript</noscript>Solo se ve cuando no hay JavaScript.
68<object>Incrusta un objeto externo, como un PDF, imagen o video.<object data="archivo.pdf" type="application/pdf"></object>Es más antigua que embed e iframe.
69<ol>Crea una lista ordenada (con números).<ol><li>Uno</li><li>Dos</li></ol>El atributo type cambia la numeración (1, A, a, I, i).
70<optgroup>Agrupa opciones dentro de una lista desplegable.<optgroup label="Frutas"><option>Mango</option></optgroup>Va dentro de select.
71<option>Define una opción de una lista desplegable.<option value="1">Opción 1</option>Va dentro de select, optgroup o datalist.
72<output>Muestra el resultado de un cálculo o acción del usuario.<output name="total">0</output>Se usa con formularios y JavaScript.
73<p>Define un párrafo de texto.<p>Este es un párrafo.</p>Puede contener otros elementos en línea.
74<picture>Ofrece varias imágenes según el tamaño de pantalla.<picture><source srcset="grande.jpg" media="(min-width:800px)"><img src="pequena.jpg" alt="Foto"></picture>Siempre termina con una etiqueta img.
75<pre>Muestra el texto tal cual, respetando espacios y saltos de línea.<pre>Linea 1 Linea 2</pre>Ideal para mostrar código.
76<progress>Muestra una barra de progreso.<progress value="70" max="100">70%</progress>Sin value es una barra indeterminada.
77<q>Define una cita corta en línea.<q>Hola mundo</q>El navegador agrega las comillas solo.
78<rp>Muestra paréntesis para navegadores sin soporte ruby.<rp>(</rp>Se usa dentro de ruby.
79<rt>Define la pronunciación de caracteres (ruby).<rt>kan</rt>Se usa en textos de Asia oriental.
80<ruby>Define una anotación de pronunciación sobre caracteres.<ruby>漢<rt>kan</rt></ruby>Se combina con rt y rp.
81<s>Muestra texto tachado que ya no es correcto.<s>Precio anterior</s>Para texto eliminado de verdad se usa del.
82<samp>Muestra la salida de un programa de computadora.<samp>Error 404</samp>Usa fuente monoespaciada.
83<script>Incluye o enlaza código JavaScript.<script src="app.js"></script>Suele ponerse al final del body.
84<search>Define una sección de búsqueda.<search><form>...</form></search>Es una etiqueta nueva de HTML5.
85<section>Define una sección temática de la página.<section><h2>Servicios</h2></section>Normalmente lleva un encabezado.
86<select>Crea una lista desplegable.<select><option>Uno</option></select>El atributo multiple permite elegir varias opciones.
87<slot>Define un espacio dentro de un Web Component.<slot name="titulo"></slot>Se usa en componentes avanzados.
88<small>Muestra texto en letra más pequeña (notas legales).<small>Términos y condiciones</small>Ideal para letra pequeña.
89<source>Define varios archivos de medios para audio, video o picture.<source src="video.mp4" type="video/mp4">No tiene etiqueta de cierre.
90<span>Define un contenedor en línea para dar estilo a parte de un texto.Mi color es <span style="color:red">rojo</span>Es como div pero no rompe la línea.
91<strong>Da importancia fuerte al texto (se ve en negrita).<strong>Importante</strong>Los lectores de pantalla lo enfatizan.
92<style>Incluye código CSS dentro del documento.<style>p { color: blue; }</style>Normalmente va en head.
93<sub>Muestra texto como subíndice.H<sub>2</sub>OÚtil en fórmulas químicas.
94<summary>Define el título visible de un bloque details.<summary>Ver más</summary>Va dentro de details.
95<sup>Muestra texto como superíndice.x<sup>2</sup>Útil en potencias.
96<table>Crea una tabla de datos.<table border="1"><tr><td>Dato</td></tr></table>Se combina con tr, th y td.
97<tbody>Agrupa las filas del cuerpo de una tabla.<tbody><tr><td>Dato</td></tr></tbody>Va después de thead.
98<td>Define una celda de datos en una tabla.<td>Dato</td>Puede unir columnas con colspan.
99<template>Guarda HTML que no se muestra hasta que JavaScript lo use.<template><p>Oculto</p></template>Su contenido no se ve en pantalla.
100<textarea>Crea un cuadro de texto de varias líneas.<textarea rows="4" cols="30"></textarea>rows y cols controlan el tamaño.
101<tfoot>Agrupa las filas del pie de una tabla.<tfoot><tr><td>Total</td></tr></tfoot>Suele usarse para totales.
102<th>Define una celda de encabezado en una tabla.<th>Nombre</th>Se ve en negrita y centrada por defecto.
